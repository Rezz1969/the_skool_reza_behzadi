# the_skool_reza_behzadi

Det här uppdraget gäller the_skool, som är en ny men relativ liten aktör.
Utifrån intervjun med stakeholdern, har företaget inga begränsningar gällande utbildning eller geografiskt område.
De kan tänka sig att starta med vilka utbildningar som helst och var som helst i Sverige.
För detta behöver de få svar på följande:

- Områden som är intressanta
- Var finns störst chans att få ansökningarna beviljade?
- Hur har statistiken sett ut senaste året och vad vill myndigheten att satsa på?
- Gärna 2-3 utbildningar ska bli godkända
- Även beviljande grad ska vara så stor som möjligt

Till vår hjälp har vi använt oss av excel-filen ao_2025.xlsx

Svar på uppgift 1 finns i directory Uppgift_1.

Svar på uppgift 3 finns i drectory Uppgift_3.

Exempel på vilka svar som finns kan ni hitta i directory Screenshots.
